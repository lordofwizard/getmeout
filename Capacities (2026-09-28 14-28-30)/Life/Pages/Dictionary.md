# Dictionary

```python
# Creating a dictionary
d = {"a": 1, "b": 2, "c": 3}

# Accessing
print(d["a"])  # 1

# Inserting
d["d"] = 4

# Deleting
del d["b"]

# Searching
print("c" in d)  # True

# Iterating
for key, value in d.items():
    print(key, value)
```
