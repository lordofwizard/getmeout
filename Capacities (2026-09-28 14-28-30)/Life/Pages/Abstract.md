# ELFS: Efficient Lossless File System

What we learned?

- How to build a lossless file system, to read data on a compressed volume.

- How to do optimise it for performance.

- How to do real time read options and mount compressed volume on a specific directory. 



 

---

Features that we are proposing. 

- Read and Write functionality on a compressed volume using patterns and dicticnoties using ZStadanrd algorithm.

- A toolchain of cli tools called as (elfs-extract, exfs-make, elfscat, elfs-mount) to use the file system in linux/unix environments.
