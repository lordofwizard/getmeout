# Rust Dev Container.

So wanted to make a dev container with rust stuff installed.

here's how to do that. 


<!-- restart numbering -->

1. Install Visual Studio Code Bin

2. install Docker on User space

3. install Dev Containers extension and obv install rust-analyser if possible.

4. now press CTRL+SHIFT+P and search for dev containers repository

5. don't select the option with Named Repository.

6. clone your project that way ... so that there will be a individual dev container just for your project. 

7. in image select ubuntu (use latest version if you want) for robonet i am using focal.

8. in additional dependencies I installed rust 

9. selected latest version 

10. thats it
